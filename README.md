# MOEX DAG

## Описание

DAG предназначен для загрузки биржевых данных (акций MOEX) и последующей передачи данных в PostgreSQL и ClickHouse.

---

## Архитектура дага

DAG состоит из следующих шагов:

### 1. start
- Тип: `EmptyOperator`


### 2. load_to_pg
- Тип: `PythonOperator`
- Назначение:
  - Получение данных из MOEX API
  - Загрузка данных в PostgreSQL
- Реализация:
  - используется `PostgresHook` (или аналогичный hook)


### 3. load_to_click
- Тип: `PythonOperator`
- Назначение:
  - Перенос данных из PostgreSQL в ClickHouse
- Реализация:
  - используется `ClickHouseHook`
  - применяется таблица с движком `PostgreSQL`

### 4. end
- Тип: `EmptyOperator`

---

## Особенности реализации

### Ограничение MOEX API
MOEX API не позволяет выгружать исторические данные за один запрос на один день.

Поэтому реализована логика выгрузки сразу за 2 дня (текущий и предыдущий), после чего данные за предыдущий день удаляются.

---

## Конфигурация тикеров

Добавление новых тикеров осуществляется через конфигурационный файл `config.py`
